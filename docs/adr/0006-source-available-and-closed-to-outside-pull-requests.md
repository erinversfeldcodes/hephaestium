# 0006. The source is available to read, and outside pull requests are not taken

## Status

Accepted

## Context

Hephaestium and Athenaeum are public repositories maintained by one person. The Stacks, from which the harness comes, is public under a licence that reserves all rights. Forge is MIT-licensed and takes issues but not outside pull requests.

- Option 1: An open-source licence, open to pull requests.
- Option 2: An open-source licence, closed to outside pull requests, as Forge is.
- Option 3: The same source-available licence as The Stacks. The code may be read. It may not be used, copied, modified, distributed or used to train a model without permission. Issues are welcome and outside pull requests are closed without review.

## Decision

We will go with Option 3 for both repositories. Bug reports and ideas arrive through issue forms, with blank issues off. Vulnerabilities are reported through GitHub's private vulnerability reporting.

## Consequences

Neither repository is open source and neither may describe itself as such. Only the copyright holder's own repositories may consume Athenaeum. Nobody else may run Hephaestium. Opening either one later is a new decision.
