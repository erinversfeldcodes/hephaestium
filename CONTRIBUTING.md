# Contributing to Hephaestium

Thank you for your interest in Hephaestium.

## Issues are welcome

Found a problem or have an idea?
[Open an issue](https://github.com/erinversfeldcodes/hephaestium/issues/new/choose)
using the bug report or idea form. A clear description of a problem is the most
useful contribution you can make.

## Pull requests are not accepted

Pull requests from outside contributors are closed without review, for two
reasons:

- **The licence does not permit it.** The source is publicly visible under a
  restrictive licence that grants no right to copy or modify it. Read
  [LICENSE](./LICENSE) before using or referencing this code.
- **Work enters as tickets.** A change here starts as a ticket that is scoped
  and approved, and is then built and proved through the project's own gates. A
  pull request against a ticket that is not yet settled would be guessing at
  its scope.

If you have a fix in mind, describe it in an issue instead. The decision is
recorded in
[ADR-0006](./docs/adr/0006-source-available-and-closed-to-outside-pull-requests.md).

## Agents

Issues and comments written by an automated agent are welcome on the same terms
as anyone's: a clear description of a problem is useful whoever wrote it. Two
things are asked of them:

- **Say so.** An account that runs an agent says in its profile or in each
  comment that an agent writes there, and who runs it.
- **Do not offer to take work.** Tickets are built by the project's own
  workers, so an offer to fix, implement or claim a ticket is not wanted.

A pull request from an agent is a pull request from an outsider, and is closed
without review. A comment that does not say it comes from an agent, or that
offers to take work, is hidden or deleted without reply.

## Security

Report vulnerabilities privately, as described in [SECURITY.md](./SECURITY.md),
never in a public issue.

## Code of conduct

All interactions are governed by the [Code of Conduct](./CODE_OF_CONDUCT.md).
